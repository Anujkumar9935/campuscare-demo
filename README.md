# CampusCare — Smart Campus Emergency & Help Hub

A static, public demo of the CampusCare campus safety and support interface.

## Demo behavior

- Runs as a static website and saves demo requests in this browser only.
- Does not notify campus staff, dispatch Safe Walk escorts, or contact emergency responders.
- Campus locations and contact details are illustrative placeholders. Verify official details before relying on them.
- The campus map is illustrative and is not connected to a real campus map.

For a local version with the demo Node backend, use the private source repository shared by the project owner.
